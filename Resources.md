# Web3 Bug Bounty Resources

A curated list of essential tools, reading materials, and platforms for smart contract auditing and bug bounty hunting.

## Tools
- **Slither**: Static analysis framework for Solidity.
- **Mythril**: Security analysis tool for EVM bytecode.
- **Foundry / Forge**: Fast, portable, and modular toolkit for Ethereum application development and testing.
- **Echidna**: Ethereum smart contract fuzzer.

## Platforms
- **Immunefi**: The leading bug bounty platform for Web3.
- **Code4rena**: Competitive smart contract auditing platform.
- **Sherlock**: Smart contract auditing marketplace.
